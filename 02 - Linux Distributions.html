02 - Linux Distributions

Linux Kernel

  • Kernel is the code that manages the hardware
  • Abstracts the hardware layer from the applications
    • Provides an interface for applications to interact with hardware
    • Application does not have to be written for specific hardware
  • Kernel manages time-sharing, multi-tasking, I/O, memory, power management and hardware devices

A Full operating system needs more than just the kernel in order to be useful. Usually, Linux Kernel is combined with GNU Project utilities, tools, and libraries in order to create a fully functional OS. The correct term for this is "GNU/Linux" indicating that the OS contains Linux Kernel and GNU software.

GNU/Linux OS (Linux Distro)

A typical Operating System is made of many software components. A GNU/Linux distribution is typically a collection of the following:

  • Linux Kernel
  • GNU Tools and Libraries
  • Package management system
  • Windowing system, Desktop Environment of other GUI components
  • Documentation
  • Additional software

The support for a Linux-based distribution can be either commercially-backed or community-backed.
For more information, you can review: https://en.wikipedia.org/wiki/Linux_distribution#
To find out the heritage of a specific distro, you may find it in this svg graphics: https://en.wikipedia.org/wiki/Linux_distribution#/media/File:2023_Linux_Distributions_Timeline.svg

Some examples of commercially backed Linux Distros:

  • RedHat Enterprise Linux (IBM) (commercial license)
    - Fedora and Fedora Workstation variants are based on RedHat
    - Has strict rules regarding source-code access and distribution since purchased by IBM
    - Package Manager: YUM (Yellow Dog Updater, Modified), RPM (RedHat Package Manager, does not support dependency resolution)
  • SUSE Enterprise Linux (commercial license)
    - Community and open version: OpenSuse variants
    - Package Manager: Zypper
    - Suse has a GUI and TUI "Control panel" called YaST which can be used to configure many aspects of the OS, including managing repositories and software
  • Ubuntu (Canonical Ltd.)
    - Based on Debian
    - contains free software and proprietary device drivers
    - Free-to-use, paid enterprise support is available from Canonical Ltd.
    - Package Managers: dpkg (apt and apt-get as front), snap, flatpak (optional)

Some examples of Community-backed Linux Distros:

  • Debian (the Debian Project)
    - Entirely free and open-source
    - Most popular, and many other distros (such as Ubuntu) are based on Debian
    - Package Managers: Debian Package Manager - dpkg (apt and apt-get as front), others (optional)
  • Arch Linux
    - Free, but NOT endorsed by GNU (kernel contains non-free and proprietary components)
    - Not suitable for business or enterprise use
    - Package Manager: pacman package manager
  • Gentoo Linux
    - Free software
    - Compiled entirely from source code, can be configured to be specifically compiled for the hardware to ensure maximum performance, but also more difficult to setup and configure
    - Package manager: Portage
